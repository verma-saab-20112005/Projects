--- Transformer NMT Project Summary

Transformer Machine Translation System

A custom PyTorch implementation of the Attention Is All You Need Transformer architecture for English-to-Italian translation.

Project Overview

  • Source Language: English (en)
  • Target Language: Italian (it)
  • Inference Strategy: Beam Search Decoding (Beam Size = 3)
  • Primary Components: Custom Transformer, FastAPI Server, Gradio Interface

Configuration & Parameters

Parameter Configured Value
Batch Size 8
Epochs 25
Learning Rate 0.001 (1e-3)
Embedding Dimension (d_embedding) 512
Max Sequence Length 350
Model Checkpoint Path weights/tmodel_24.pt

System Endpoints

Type Endpoint/Method Description
GET / Health check status
POST /translate Translates source English text to Italian
