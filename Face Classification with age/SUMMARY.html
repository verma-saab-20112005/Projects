--- UTKFace Dataset Parsing Summary

Project Data Processing Summary

This document summarizes the initial data loading and feature extractions performed on the UTKFace dataset for age and gender prediction.

Loaded Dependencies

pandas numpy tensorflow keras os

Extracted Attributes Breakdown

Attribute Description Extracted Data Type
Age Parsed integer from filename index 0 (e.g., 1 to 116 years old) Integer
Gender Parsed integer from filename index 1 (0 = Male, 1 = Female) Integer
Image Path Original file name inside directory for reading image tensors String
Database Note: The UTKFace image files were parsed locally via directory iteration. The dataset itself is excluded from code uploads due to storage limitations.
